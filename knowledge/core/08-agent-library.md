# The specialist AI agent library

VARA maintains a library of **180+ specialist AI agent definitions** across 12 domains. Each one is a configured AI worker with a defined role, tools and operating procedure. This is what lets VARA assemble a working AI team for a client quickly rather than starting from zero.

Use this when someone asks "what can AI actually do for us?" or "can you build an agent that…?" — the honest answer is almost always yes, and here is the shape of it.

## Why this matters to a client
- **Speed.** A new AI workflow starts from a proven definition, not a blank page.
- **Coverage.** Whether the need is admissions, marketing, support, QA or compliance, there's already a specialist shape for it.
- **Orchestration.** Agents can be run together — one plans, several execute in parallel, another reviews the output before a human sees it.

## The honest framing
These are agent *definitions* and operating procedures — the blueprints VARA works from. Each still needs configuring against a client's own systems, data and rules during a build. Do not present the library as 180 ready-to-switch-on products.
